Structure:
1. Load PARALLEL_API_KEY from env (os.getenv, not dotenv — dotenv is loaded at pipeline entry in run_pipeline.py)
2. BASE_URL = "https://api.parallel.ai/v1"

Functions:
- `async def create_task_run(input_text: str, output_description: str = "Detailed startup research report in Russian with citations", processor: str = "core") -> str`:
  POST to /tasks/runs, returns run_id string. Raises on HTTP error (let caller handle retries).

- `async def get_task_result(run_id: str, timeout: int = 600) -> dict`:
  GET /tasks/runs/{run_id}/result?timeout={timeout}. Returns the full response dict (with output.content and output.basis). Raises on HTTP error or timeout.

- `async def run_deep_research_task(input_text: str, output_description: str = "Detailed startup research report in Russian with citations") -> dict`:
  Convenience function: create_task_run + get_task_result. Returns {"content": str, "citations": list[dict]} where citations are extracted from output.basis using **two-level iteration** (see CRITICAL note below). On failure returns {"content": "(Deep research failed: {error})", "citations": []}.

**CRITICAL — citations extraction (two-level iteration):**

`output.basis` is a list of "basis items" — each basis item wraps a `citations` array. The naive flat-list iteration causes KeyError at runtime. Use this exact pattern:

```python
def extract_citations(output: dict) -> list[dict]:
    # output.basis structure: [{field, reasoning, citations: [{url, title, excerpts}], confidence}]
    citations = []
    for basis_item in output.get("basis", []):
        for citation in basis_item.get("citations", []):
            citations.append({
                "url": citation.get("url", ""),
                "title": citation.get("title", ""),
                "excerpt": citation.get("excerpts", [""])[0][:200] if citation.get("excerpts") else "",
            })
    return citations
```

Source: Parallel AI OpenAPI spec (verified in 02-RESEARCH.md Pitfall 2). Also log the full `output` dict for the first successful task run to confirm the structure.

Error handling:
- create_task_run and get_task_result raise httpx.HTTPStatusError on 4xx/5xx
- run_deep_research_task catches all exceptions and returns fallback dict (never raises)
- Log errors via logging.getLogger("parallel_client")

Add to .env.example after the EXA_API_KEY line:
