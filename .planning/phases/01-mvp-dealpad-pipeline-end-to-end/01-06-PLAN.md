You are a startup classifier for iFree, a tech company focused on AI/ML, fintech, gamedev, developer tools, infrastructure, and automation.

**Name:** {name}

Primary: AI/ML, fintech, gamedev, developer tools, infrastructure, automation
Adjacent: SaaS, B2B, marketplace, analytics, data, cybersecurity, cloud, API, platform, robotics, edtech, healthtech, legaltech, logistics, HR tech, proptech

## Classification Instructions

Answer these 5 questions based on available information:

1. **is_tech** — Is this a technology company? (true/false)
   - true: software, SaaS, AI, platform, app, API, data, cloud, developer tools, robotics
   - false: physical retail, agriculture, food service, real estate development, manual services

2. **sector** — Primary sector as a short string (e.g., "AI/ML", "fintech", "developer tools", "healthtech", "robotics", "energy")

3. **sector_match** — Does this match iFree's thesis sectors?

   - "b2b": sells to businesses
   - "b2c": sells to consumers
   - "both": serves both
   - "unknown": cannot determine from description

{"is_tech": true, "sector": "AI/ML", "sector_match": "yes", "product_type": "software", "b2b_b2c": "b2b"}

Rewrite pipeline/prefilter.py with two stages + graceful LLM failure:

Imports: asyncio, os, pathlib.Path, shutil, yaml, frontmatter, re, from lib.llm import call_llm, load_prompt, from lib.utils import load_idea, save_idea

Constants:
- IDEAS_DIR = Path("1_ideas")
- ARCHIVE_DIR = Path("_archive")
- FILTERS_PATH = Path("config/filters.yaml")

Function `def load_filters() -> dict`:
- yaml.safe_load from FILTERS_PATH

Function `def hard_reject(post: frontmatter.Post, filters: dict) -> str | None`:
- Check description length < min_description_length → "description_too_short"
- Check exclude_niches keyword match (keep existing word-boundary regex) → "excluded_niche:{keyword}"
- Check round_usd >= max_round_usd → "round_too_large"
- Return rejection reason string or None

Function `async def classify_one(post: frontmatter.Post, prompt_template: str) -> dict`:
- Build prompt using .replace() for {name}, {url}, {round_raw}, {description}
- Call LLM with json_mode=True, model=OPENROUTER_MODEL_LIGHT
- REQUIRED_KEYS = {"is_tech", "sector", "sector_match", "product_type", "b2b_b2c"}
- If call succeeds and all keys present:
    return {**result, "classification_status": "classified"}
- If call fails or keys missing:
    return FALLBACK dict:
    {"is_tech": True, "sector": "unknown", "sector_match": "partial",
     "product_type": "unknown", "b2b_b2c": "unknown",
     "classification_status": "failed", "review_needed": True}
  NOTE: fallback defaults to is_tech=True, sector_match="partial" so the idea
  passes through to scoring rather than being falsely rejected. The "failed"
  status and review_needed flag let downstream steps and humans identify these.

Function `def compute_eligibility(post: frontmatter.Post) -> tuple[bool, bool]`:
- NOTE: Round size is NOT used as eligibility gate — it's a scoring factor in quick_score
- invest_eligible = (post.get("is_tech") == True) AND (post.get("sector_match") in ("yes", "partial"))
- build_eligible = (post.get("is_tech") == True) AND (post.get("sector_match") in ("yes", "partial")) AND (post.get("product_type") in ("software", "service", "unknown"))
  NOTE: "unknown" product_type passes build — don't reject on classification failure
- Return (invest_eligible, build_eligible)

Function `async def run_prefilter() -> dict`:
- Load filters, load classify prompt
- Stage A: iterate all 1_ideas/*.md
  - Skip already-processed (have "classification_status" in frontmatter)
  - Apply hard_reject → archive rejects with filter_reason
  - Collect survivors for classification
- Stage B: run classify_one on all survivors via asyncio.gather(return_exceptions=True)
  - For exceptions: use same fallback dict as classify_one failure
  - Write classification fields to frontmatter: is_tech, sector, sector_match, product_type, b2b_b2c, classification_status, review_needed (if failed)
- Stage C: compute eligibility for each classified idea
  - Write invest_eligible and build_eligible to frontmatter
  - Write filtered="passed" for backward compat
  - Archive those with BOTH false AND classification_status != "failed"
    (never archive classification failures — they get review_needed instead)
- Print summary: "Pre-filter: {hard} hard rejected, {classified} classified ({failed} LLM failures → review_needed), {invest} invest-eligible, {build} build-eligible, {archived} archived"
- Return stats dict

Rewrite pipeline/quick_score.py with formula-based scoring:

Imports: asyncio, os, pathlib.Path, yaml, frontmatter, from lib.llm import call_llm, load_prompt, from lib.utils import load_idea, save_idea

Constants:
- IDEAS_DIR = Path("1_ideas")
- FORMULA_PATH = Path("config/scoring_formula.yaml")

Function `def load_formula() -> dict`:
- yaml.safe_load from FORMULA_PATH

Function `def compute_round_fit(round_usd: int | None) -> str`:
- If round_usd is None: return "far"
- If 30_000 <= round_usd <= 300_000: return "in_range"  # ideal iFree check size
- If 300_000 < round_usd <= 2_000_000: return "close"   # early stage, possible
- Else: return "far"  # too small or too large, but NOT disqualifying

Function `def compute_score(answers: dict, formula: dict) -> int`:
- total = 0
- For each factor_name, value_map in formula.items():
    answer_value = answers.get(factor_name, "unknown")
    if isinstance(answer_value, str): answer_value = answer_value.lower()
    points = value_map.get(answer_value, 0)
    total += points
- Return max(0, min(10, total))

Function `async def score_one_idea(post: frontmatter.Post, prompt_template: str) -> dict | None`:
- Build prompt using .replace() for {name}, {url}, {round_raw}, {description}, {sector} (from prefilter frontmatter), {product_type} (from prefilter frontmatter)
- Call LLM with json_mode=True, model=OPENROUTER_MODEL_LIGHT
- REQUIRED_KEYS = {"has_product_signal", "founder_signal", "cis_transferable", "uniqueness", "market_potential", "one_liner", "category", "invest_rationale", "build_rationale"}
- Return parsed dict or None on failure

Function `async def run_quick_score() -> dict`:
- Load formula config and prompt template
- Scan IDEAS_DIR for ideas with filtered=="passed" and no invest_score yet
- Score each via asyncio.gather(return_exceptions=True)
- For each successful result:
    - Build answers dict by merging:
      a. From prefilter frontmatter: sector_match, product_type, b2b_b2c
      b. From LLM response: has_product_signal (key: "has_product"), founder_signal, cis_transferable, uniqueness, market_potential
      c. Mechanical: round_fit = compute_round_fit(post.get("round_usd"))
    - Compute invest_score = compute_score(answers, formula["invest_formula"])
    - Compute build_score = compute_score(answers, formula["build_formula"])
    - Write ALL to frontmatter: has_product_signal, founder_signal, cis_transferable, uniqueness, market_potential, round_fit, invest_score, build_score, one_liner, category, invest_rationale, build_rationale
    - save_idea
- Build shortlist from config thresholds:
    invest_threshold = formula["shortlist"]["invest_threshold"]
    build_threshold = formula["shortlist"]["build_threshold"]
    Shortlist if: invest_score >= invest_threshold OR build_score >= build_threshold
- Print summary with score distribution
- Return stats dict
