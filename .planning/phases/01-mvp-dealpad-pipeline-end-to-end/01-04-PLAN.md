Function `async def research_one(post: frontmatter.Post, slug: str) -> dict`:
- Create research_dir = RESEARCH_DIR / slug
- research_dir.mkdir(parents=True, exist_ok=True)
- Step 1: Scrape website
  a. url = post.get("url", "")
  b. website_text = await scrape_website(url) if url else ""
  c. Write website.md to research_dir:
     Content: f"# Website Content: {post.get('name', slug)}\n\n**URL:** {url}\n**Scraped:** {datetime.utcnow().isoformat()}\n\n{website_text if website_text else '(Website could not be reached)'}"
- Step 2: LLM research synthesis (using model's training data -- NOT real web search)
  a. Build prompt:
     f"You are a startup analyst. Based on the following information about a startup, provide a research summary.\n\n"
     f"Name: {post.get('name')}\n"
     f"URL: {url}\n"
     f"Round: {post.get('round_raw', 'Unknown')}\n"
     f"Description: {post.content}\n"
     f"Website content: {website_text[:2000]}\n\n"
     f"Provide a research summary covering: what the company does, founders (if known), business model, competitive landscape, traction signals, and potential risks.\n"
     f"Return as JSON with keys: summary, founders, business_model, competitors, traction, risks"
  b. result = await call_llm(prompt, model=os.getenv("OPENROUTER_MODEL_LIGHT"), json_mode=True)
  c. Write web_research.md to research_dir:
     Header: "# Research Summary: {name}\n\n> Note: This research is synthesized from the startup's website and LLM training data. It is NOT based on real-time web search.\n\n"
     Then format the result dict into readable sections (Summary, Founders, Business Model, Competitors, Traction, Risks)
- Return {"slug": slug, "website_scraped": bool(website_text), "research_dir": str(research_dir)}

Create pipeline/deep_analysis.py that performs full invest + build scoring via the heavy LLM model.

Imports: asyncio, pathlib.Path, os, json, yaml, frontmatter, from lib.llm import call_llm, load_prompt, from lib.utils import make_slug, load_idea

Constants:
- IDEAS_DIR = Path("1_ideas")
- RESEARCH_DIR = Path("2_research")
- ANALYSIS_DIR = Path("3_analysis")
- WEIGHTS_PATH = Path("config/scoring_weights.yaml")

Function `def load_weights() -> dict`:
- Parse and return config/scoring_weights.yaml

Function `def compute_weighted_score(scores: dict, weights: dict) -> float`:
- For each criterion in weights, multiply score * weight
- Sum all weighted scores
- Return rounded to 1 decimal: round(total, 1)

Function `def determine_verdict(score: float, thresholds: dict) -> str`:
- For invest: score >= 8.0 -> "INVEST", score >= 6.0 -> "WATCH", else "PASS"
- For build: score >= 8.0 -> "BUILD", score >= 6.0 -> "PARTNER", score >= 4.0 -> "MONITOR", else "SKIP"
- Use thresholds dict from scoring_weights.yaml to drive this (not hardcoded values)
- Iterate thresholds in descending order: if score >= threshold_value, return threshold_name.upper()

Function `async def analyze_one(post: frontmatter.Post, slug: str, research_dir: Path, prompt_template: str, weights: dict) -> dict`:
- Load research data:
  a. website_content = (research_dir / "website.md").read_text(encoding="utf-8") if file exists, else ""
  b. research_notes = (research_dir / "web_research.md").read_text(encoding="utf-8") if file exists, else ""
- Build prompt by substituting template variables in prompt_template:
  - {name} = post.get("name", slug)
  - {url} = post.get("url", "")
  - {round_raw} = post.get("round_raw", "Unknown")
  - {description} = post.content
  - {website_content} = website_content[:3000]
  - {research_notes} = research_notes[:3000]
- Call: result = await call_llm(prompt, model=os.getenv("OPENROUTER_MODEL_HEAVY"), json_mode=True, temperature=0.2)
- If result is an Exception, raise it
- Extract invest_scoring and build_scoring dicts from result
- Compute weighted totals:
  a. invest_total = compute_weighted_score(invest_scoring, weights["invest_mode"]["criteria"]) -- extract just the score values from the scoring dicts (each criterion may be {score: N, rationale: "..."})
  b. build_total = compute_weighted_score(build_scoring, weights["build_mode"]["criteria"])
- Determine verdicts using thresholds from weights
- Build analysis dict with all data
- Write analysis file to ANALYSIS_DIR / f"{slug}_analysis.md":
  Frontmatter: name, url, invest_total, build_total, invest_verdict, build_verdict, analyzed_at
  Content body in Markdown:
  ```
  # Analysis: {name}
  
  ## Invest Score: {invest_total}/10 — {invest_verdict}
  {for each criterion: criterion_name: score/10 — rationale}
  
  ## Build Score: {build_total}/10 — {build_verdict}
  {for each criterion: criterion_name: score/10 — rationale}
  
  ## Red Flags
  {bullet list from result.get("red_flags", [])}
  
  ## Green Flags
  {bullet list from result.get("green_flags", [])}
  
  ## CIS Adaptation
  {result.get("cis_adaptation", "N/A")}
  
  ## Risks
  {bullet list from result.get("risks", [])}
  
  ## Next Steps
  {bullet list from result.get("next_steps", [])}
  ```
- Return the analysis dict

Function `async def run_deep_analysis(slugs: list[str] | None = None) -> dict`:
- Load prompt_template = load_prompt("deep_analysis")
- Load weights = load_weights()
- ANALYSIS_DIR.mkdir(parents=True, exist_ok=True)
- If slugs is None, scan RESEARCH_DIR for all subdirectories that have web_research.md
- For each slug:
  a. Find matching idea file in IDEAS_DIR (search for file where frontmatter name slug-matches)
  b. IDEMPOTENCY: if ANALYSIS_DIR / f"{slug}_analysis.md" exists, skip
  c. Add to analysis_tasks list
- Print: f"Analyzing {len(analysis_tasks)} startups (skipping {skipped} already analyzed)..."
- Run with asyncio.gather(*tasks, return_exceptions=True)
- Count successes/failures
- Print summary: f"Analysis complete: {success_count} analyzed, {fail_count} failed"
- Return {"analyzed": success_count, "failed": fail_count}
