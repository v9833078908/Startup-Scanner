Create scouts/dealpad_parser.py that parses Telegram Desktop HTML export from the DealPad channel.

Imports: pathlib.Path, datetime, re, bs4.BeautifulSoup, frontmatter, and from lib.utils import make_slug, parse_round_usd, parse_date

Constants:
- IDEAS_DIR = Path("1_ideas")
- SPAM_KEYWORDS = ["обзоры", "fastfounder"] (lowercase, for case-insensitive matching)

Function `def parse_html_file(html_path: str | Path) -> list[dict]`:
- Read file with encoding="utf-8"
- Parse with BeautifulSoup(content, "lxml")
- Select all `div.message.default.clearfix` elements via soup.select("div.message.default.clearfix")
- For each message div:
  a. Extract message_id from div's "id" attribute (e.g., "message12345" -> "12345")
  b. Extract post_date from div.find("div", class_="date") or div.select_one(".date.details") -- get the "title" attribute which contains "DD.MM.YYYY HH:MM:SS"
  c. Parse post_date: split on " " take first part, reformat from DD.MM.YYYY to YYYY-MM-DD
  d. Extract text_el = div.find("div", class_="text") -- skip if None
  e. Get full_text = text_el.get_text(separator="\n", strip=True)
  f. SPAM CHECK: if any keyword from SPAM_KEYWORDS appears in full_text.lower(), skip this message
  g. Extract links = text_el.find_all("a")
  h. name = first link's text if links exist, else try first line of full_text
  i. url = first link's "href" if links exist, else ""
  j. Parse round info: search full_text for pattern containing currency + amount. Use regex on full_text to find round line. The DealPad format often has a line like "Раунд: $XXX, Month YYYY" or "$XXX round". Extract round_raw as the matched string, round_usd via parse_round_usd(round_raw), round_date via parse_date on the date portion.
  k. description: everything after the URL line / round line. Take full_text, remove the name line and round line, use the remainder as description. If parsing is ambiguous, use the full_text as description.
  l. Build dict: {name, url, round_raw, round_usd, round_date, description, message_id, post_date}
- Return list of all parsed dicts (skip empties where name is empty/None)

Function `def save_ideas(ideas: list[dict], output_dir: Path = IDEAS_DIR) -> int`:
- output_dir.mkdir(parents=True, exist_ok=True)
- saved_count = 0
- For each idea dict:
  a. slug = make_slug(idea["name"])
  b. date_prefix = idea["post_date"] or datetime.date.today().isoformat()
  c. filename = f"{date_prefix}_{slug}.md"
  d. output_path = output_dir / filename
  e. IDEMPOTENCY CHECK: if output_path.exists(), skip (continue)
  f. Create frontmatter.Post with:
     content = f"# {idea['name']}\n\n**URL:** {idea['url']}\n**Round:** {idea['round_raw']}\n\n{idea['description']}"
     metadata keys: name, url, round_usd, round_raw, round_date, source="dealpad", source_id=idea["message_id"], parsed_at=datetime.datetime.utcnow().isoformat()
  g. Write with frontmatter.dumps(post), encoding utf-8
  h. saved_count += 1
- Return saved_count

- html_path = Path(html_input)
- MULTI-FILE SUPPORT: if html_path is a file, find sibling files: sorted(html_path.parent.glob("messages*.html")) -- parse all of them. If html_path is a directory, glob for messages*.html inside it.
- Combine all parsed ideas from all files
- Call save_ideas() and return total saved count

Create pipeline/prefilter.py that reads all ideas from 1_ideas/, applies filters.yaml criteria, and moves rejects to _archive/.

Imports: pathlib.Path, re, shutil, yaml, frontmatter (python-frontmatter), from lib.utils import load_idea, save_idea

Constants:
- IDEAS_DIR = Path("1_ideas")
- ARCHIVE_DIR = Path("_archive")
- CONFIG_PATH = Path("config/filters.yaml")

Function `def load_filters() -> dict`:
- Read and parse config/filters.yaml
- Return the dict

Function `def matches_niches(text: str, niches: list[str]) -> bool`:
- For each keyword in niches:
  Use word-boundary regex: re.search(r'\b' + re.escape(keyword) + r'\b', text, re.IGNORECASE)
  If any match, return True
- Return False
- IMPORTANT: Use word boundaries (\b) to avoid "AI" matching "rail" or "wait" (Pitfall 5 from RESEARCH.md)

Function `def check_filters(post: frontmatter.Post, filters: dict) -> str | None`:
- Returns rejection reason string, or None if idea passes all filters
- Check 1 - description length: get post.content or post.get("description", ""). If len < filters["min_description_length"], return "description_too_short"
- Check 2 - exclude niches: combine post.content + post.get("name", "") into text. If matches_niches(text, filters["exclude_niches"]), return "excluded_niche:{matched_keyword}"
- Check 3 - include niches: if filters["include_niches"] is non-empty, check if matches_niches(text, filters["include_niches"]). If NO match, return "no_matching_niche"
- Check 4 - round size: round_usd = post.get("round_usd"). If round_usd is not None:
  - if filters.get("min_round_usd") and round_usd < filters["min_round_usd"]: return "round_too_small"
  - if filters.get("max_round_usd") and round_usd > filters["max_round_usd"]: return "round_too_large"
- Return None (passes all filters)

Function `def run_prefilter() -> dict`:
- Load filters via load_filters()
- ARCHIVE_DIR.mkdir(parents=True, exist_ok=True)
- Iterate over all .md files in IDEAS_DIR (sorted)
- For each file:
  a. post = load_idea(file_path)  
  b. Skip if already has "filtered" key in frontmatter (idempotency)
  c. reason = check_filters(post, filters)
  d. If reason is not None:
     - post["filtered"] = "rejected"
     - post["filter_reason"] = reason
     - save_idea(post, file_path)  # update frontmatter before moving
     - shutil.move(str(file_path), str(ARCHIVE_DIR / file_path.name))
     - rejected_count += 1
  e. If reason is None:
     - post["filtered"] = "passed"
     - save_idea(post, file_path)  # mark as passed for idempotency
     - passed_count += 1
- Print summary: f"Pre-filter complete: {passed_count} passed, {rejected_count} rejected (archived)"
- Return {"passed": passed_count, "rejected": rejected_count}
