Create pipeline/quick_score.py that scores all pre-filtered ideas via async OpenRouter LLM calls.

Imports: asyncio, pathlib.Path, os, json, frontmatter, from lib.llm import call_llm, load_prompt, from lib.utils import load_idea, save_idea

Constants:
- IDEAS_DIR = Path("1_ideas")
- SHORTLIST_THRESHOLD_INVEST = 6
- SHORTLIST_THRESHOLD_BUILD = 6

Function `async def score_one_idea(post: frontmatter.Post, prompt_template: str) -> dict | None`:
- Build the prompt by substituting template variables in prompt_template:
  - {name} = post.get("name", "Unknown")
  - {url} = post.get("url", "")
  - {round_raw} = post.get("round_raw", "Unknown")
  - {description} = post.content (the markdown body after frontmatter)
- Call: result = await call_llm(prompt, model=os.getenv("OPENROUTER_MODEL_LIGHT"), json_mode=True)
- If result is an Exception or None, return None
- Validate result has required keys: invest_score, build_score, category, one_liner, invest_rationale, build_rationale
- Coerce scores to int: invest_score = int(result.get("invest_score", 0)), same for build_score
- Clamp scores to 1-10 range: max(1, min(10, score))
- Return the validated result dict

Function `async def run_quick_score() -> dict`:
- Load prompt template: prompt_template = load_prompt("quick_score")
- Collect all .md files from IDEAS_DIR that have frontmatter "filtered" == "passed"
- For each file, load with load_idea()
- IDEMPOTENCY: skip files that already have "invest_score" in frontmatter
- Build list of (file_path, post) tuples to score
- Print: f"Quick scoring {len(to_score)} ideas (skipping {skipped} already scored)..."
- Create async tasks: for each (path, post), call score_one_idea(post, prompt_template)
- Run with asyncio.gather(*tasks, return_exceptions=True)
- Process results:
  a. For each successful result (not Exception, not None):
     - Update the post's frontmatter: post["invest_score"] = result["invest_score"], post["build_score"] = result["build_score"], post["category"] = result["category"], post["one_liner"] = result["one_liner"], post["invest_rationale"] = result["invest_rationale"], post["build_rationale"] = result["build_rationale"]
     - save_idea(post, file_path)
     - scored_count += 1
  b. For failures: log error, failed_count += 1
- Build shortlist: re-scan IDEAS_DIR for all files with invest_score >= 6 OR build_score >= 6
- Print summary: f"Scored: {scored_count}, Failed: {failed_count}, Shortlisted: {len(shortlist)}"
- Return {"scored": scored_count, "failed": failed_count, "shortlist": shortlist_paths, "shortlist_count": len(shortlist)}

Add `if __name__ == "__main__":` block:
- asyncio.run(run_quick_score())
