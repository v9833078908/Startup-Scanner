<objective>
Extend triage stage to add build-specific signals (replicability, cis_gap_likelihood, stack_fit), compute a route field (invest/build/both/skip), and tighten the build_candidate definition.

Purpose: Currently all triaged startups enter the same research pipeline regardless of invest vs build interest. The route field enables downstream pipeline stages (Plans 02-03) to fork into invest-specific and build-specific tracks. The tighter build_candidate definition reduces the pass rate from ~78% to ~20-30%.

Output: Updated triage prompt, config, pipeline module, and schema.
</objective>

   def compute_route(invest_priority: str, build_candidate: bool) -> str:
