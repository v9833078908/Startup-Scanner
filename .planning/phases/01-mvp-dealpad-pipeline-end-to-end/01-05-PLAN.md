Create pipeline/digest_generator.py that reads all analysis files and generates a complete weekly digest.

Imports: asyncio, pathlib.Path, os, json, datetime, frontmatter, from lib.llm import call_llm, load_prompt, from lib.utils import load_idea

Constants:
- IDEAS_DIR = Path("1_ideas")
- ANALYSIS_DIR = Path("3_analysis")
- ARCHIVE_DIR = Path("_archive")
- DIGESTS_DIR = Path("digests")

Function `def collect_pipeline_stats() -> dict`:
- Count total ideas: len(list(IDEAS_DIR.glob("*.md")))
- Count archived: len(list(ARCHIVE_DIR.glob("*.md")))
- Count scored: count ideas in IDEAS_DIR with invest_score in frontmatter
- Count shortlisted: count ideas with invest_score >= 6 OR build_score >= 6
- Count analyzed: len(list(ANALYSIS_DIR.glob("*_analysis.md")))
- Return dict with all counts

Function `def collect_analyses() -> list[dict]`:
- Read each *_analysis.md file from ANALYSIS_DIR
- Load frontmatter and content
- Build list of dicts with: name, url, invest_total, build_total, invest_verdict, build_verdict, category (from matching idea file if available), round_raw, and the full content text
- Sort by invest_total descending
- Return the list

Function `def build_digest_data(stats: dict, analyses: list[dict]) -> str`:
- Build a JSON string of all data to pass to the LLM digest prompt
- Include stats dict and full analyses list
- Return JSON string

Function `async def generate_digest_with_llm(data_json: str) -> str`:
- Load prompt template from prompts/digest.md
- Substitute {analysis_data} with data_json
- If total data is small enough (< 50 analyses), call LLM:
  result = await call_llm(prompt, model=os.getenv("OPENROUTER_MODEL_LIGHT"), json_mode=False, temperature=0.3)
  Return result (the raw markdown string)
- If data is too large or LLM call fails, fall back to build_digest_manually()

Function `def build_digest_manually(stats: dict, analyses: list[dict]) -> str`:
- FALLBACK: Build the digest without LLM using string formatting
- This ensures the digest is always produced even if LLM fails
- Build Markdown string with sections:

```
# Startup Scouting Digest -- Week of {today}

## Pipeline Summary
- **Parsed:** {stats['total']} startups from DealPad
- **After pre-filter:** {stats['total'] - stats['archived']} relevant ({stats['archived']} archived)
- **Quick-scored:** {stats['scored']}
- **Shortlisted:** {stats['shortlisted']} for deep research
- **Fully analyzed:** {stats['analyzed']}

## INVEST Candidates (score >= 8)
{for each analysis where invest_verdict == "INVEST":
### {name} -- {invest_total}/10
**Round:** {round_raw} | **Category:** {category}
**URL:** {url}
{extract invest rationale from content}
**Key Risk:** {extract first risk from content}
}

## WATCH List (score 6-7.9)
| Name | Score | Category | Round | One-liner |
|------|-------|----------|-------|-----------|
{for each where invest_verdict == "WATCH": table row}

## BUILD Opportunities (build_score >= 6)
{for each where build_verdict in ["BUILD", "PARTNER"]:
### {name} -- Build Score: {build_total}/10
**What to build:** {extract from content}
**CIS Adaptation:** {extract from content}
**iFree Fit:** {extract from content}
}

## Trends This Week
{count categories across all analyses, list top 5 by frequency}

## All Scored Startups
| Name | Invest | Build | Category | Round | Invest Verdict | Build Verdict |
|------|--------|-------|----------|-------|----------------|---------------|
{for each analysis: table row, sorted by invest_total desc}
```

- Return the Markdown string

Function `async def run_digest() -> dict`:
- DIGESTS_DIR.mkdir(parents=True, exist_ok=True)
- stats = collect_pipeline_stats()
- analyses = collect_analyses()
- If no analyses found, print warning and create minimal digest with just stats
- Try LLM generation first: digest_md = await generate_digest_with_llm(build_digest_data(stats, analyses))
- If LLM fails or result is too short (< 200 chars), fall back: digest_md = build_digest_manually(stats, analyses)
- Generate filename: today = datetime.date.today(); week_num = today.isocalendar()[1]; filename = f"{today.year}-W{week_num:02d}_weekly.md"
- Write to DIGESTS_DIR / filename
- Print: f"Digest saved to {DIGESTS_DIR / filename}"
- Return {"digest_path": str(DIGESTS_DIR / filename), "stats": stats, "analysis_count": len(analyses)}

Add `if __name__ == "__main__":` block:

Function `async def main(html_path: str)`:
- Print banner: "=== Startup Scouting Pipeline ==="
- Print: f"Input: {html_path}"
- total_start = time.time()

- Step 1: Parse DealPad
  print("\n[1/6] Parsing DealPad HTML export...")
  step_start = time.time()
  parsed_count = parse_dealpad(html_path)
  print(f"  Done in {time.time() - step_start:.1f}s")

- Step 2: Pre-filter
  print("\n[2/6] Applying pre-filter...")
  step_start = time.time()
  filter_result = run_prefilter()
  print(f"  Done in {time.time() - step_start:.1f}s")

- Step 3: Quick Score
  print("\n[3/6] Quick scoring via LLM...")
  step_start = time.time()
  score_result = await run_quick_score()
  print(f"  Done in {time.time() - step_start:.1f}s")

- Step 4: Deep Research
  print("\n[4/6] Deep research on shortlisted startups...")
  step_start = time.time()
  research_result = await run_deep_research()
  print(f"  Done in {time.time() - step_start:.1f}s")

- Step 5: Deep Analysis
  print("\n[5/6] Deep analysis via LLM...")
  step_start = time.time()
  analysis_result = await run_deep_analysis()
  print(f"  Done in {time.time() - step_start:.1f}s")

- Step 6: Digest
  print("\n[6/6] Generating weekly digest...")
  step_start = time.time()
  digest_result = await run_digest()
  print(f"  Done in {time.time() - step_start:.1f}s")

- Print final summary:
  total_time = time.time() - total_start
  print(f"\n{'='*50}")
  print(f"Pipeline complete in {total_time:.1f}s")
  print(f"  Parsed: {parsed_count} ideas")
  print(f"  Filtered: {filter_result.get('passed', '?')} passed, {filter_result.get('rejected', '?')} rejected")
  print(f"  Scored: {score_result.get('scored', '?')}, Shortlisted: {score_result.get('shortlist_count', '?')}")
  print(f"  Researched: {research_result.get('researched', '?')}")
  print(f"  Analyzed: {analysis_result.get('analyzed', '?')}")
  print(f"  Digest: {digest_result.get('digest_path', '?')}")
