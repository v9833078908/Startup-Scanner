# Startup Scouting Pipeline

## Vision
Автоматизированная система скаутинга стартапов и идей для iFree — технологической компании, запускающей инвестиционную активность и параллельно ищущей идеи для собственных продуктов.

## Problem
Российский венчурный рынок сломан, но это создаёт возможность: конкуренция за сделки минимальна, оценки ниже. На глобале — десятки запусков в день. Проблема не в отсутствии стартапов, а в том, чтобы найти правильные. Ручной мониторинг 15+ источников — невозможен.

## Solution
Git-репозиторий с тремя папками (`1_ideas/`, `2_research/`, `3_analysis/`) и набор Python-скриптов. Никаких баз данных, фреймворков, деплоя на серверы. Всё в Markdown, всё под версионным контролем.

Два режима работы из одного потока данных:
- **Invest mode** — найти стартапы для инвестиций ($30K–$300K, seed/early growth)
- **Build mode** — найти горячие ниши, open-source проекты и идеи для собственных продуктов iFree

## Users
- **Дина + инвестиционная команда** — ежедневный дайджест, принятие решений
- **Техническая команда iFree** — build opportunities, open-source gems
- **Акционеры** — стратегические отчёты (первое демо — 15 апреля 2026)

## Key Constraints
- MVP дедлайн: 13 апреля 2026 (демо акционерам 15 апреля)
- Архитектура: файлы + скрипты + git, никаких БД/серверов
- LLM: OpenRouter API (openai-совместимый), модели через .env
- Human-in-the-loop: автоматизация собирает и анализирует, решения принимает человек
- Все промпты в отдельной папке `prompts/`, никогда в коде
- Python, venv, async/await

## Tech Stack
- Python 3.12+ с venv
- httpx (async HTTP), beautifulsoup4 (scraping), feedparser (RSS)
- openai SDK → OpenRouter API (два уровня моделей: light и heavy)
- telethon (Telegram парсинг)
- pyyaml, python-dotenv
- Git для версионирования данных

## Investment Thesis
- Фокус: AI/ML, fintech, gamedev, developer tools, infrastructure, automation
- География: Россия + глобал
- Чек: $30K–$300K за сделку
- Стадия: seed / ранний рост
- Воронка: ~30 стартапов → 1–2 инвестиции
- Главный фильтр: сильные фаундеры — команда важнее идеи

## Success Criteria
1. MVP работает end-to-end: DealPad HTML → дайджест за один запуск
2. 15 парсеров покрывают все ключевые источники
3. Дайджест приходит каждое утро с рекомендациями
4. Invest + Build скоринг по критериям из тезиса
5. Система работает автономно через cron
